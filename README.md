# onuvutir-pata
অনুভূতির পাতা — বাংলা উপন্যাস, গল্প, কবিতা ও অনুভূতিময় উক্তির একটি সুন্দর অনলাইন প্ল্যাটফর্ম। এখানে পাঠকরা বিভিন্ন ধরনের উপন্যাস ও গল্প পড়তে, প্রিয় উক্তি সংরক্ষণ করতে এবং বন্ধুদের সঙ্গে শেয়ার করতে পারবেন। সাহিত্যপ্রেমী মানুষের জন্য তৈরি এই ওয়েবসাইটে থাকবে ভালোবাসা, অনুভূতি, সম্পর্ক, জীবন ও কল্পনার নানা গল্প।
